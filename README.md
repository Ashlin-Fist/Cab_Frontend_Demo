# CabGo — Part 1 Frontend

Next.js frontend prototype for the cab booking platform.

## Includes
- Login / OTP demo
- Responsive customer dashboard
- From / To booking form
- Multiple middle stops
- Map/GPS visual placeholder
- Ride selection
- Transparent fare summary
- Promo code UI
- Split payment UI
- Recent rides
- AI assistant UI
- Mobile responsive navigation

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000

This part is frontend-only. Maps, authentication, payments, GPS, AI, chat and backend persistence are UI placeholders and will be connected in later parts.
